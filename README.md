# Integrated developmental atlas of the mouse cochlear sensory epithelium

This repository contains the analysis and figure-reproduction code for the manuscript “An integrated developmental atlas of the mouse cochlear sensory epithelium reveals developmental branching, hair cell maturation and divergent USH2A transcript expression between mouse and macaque.”

Only source code and the minimum files needed to understand or run it are tracked. Raw data, processed single-cell objects, trained models and generated figures are not included.

## Contents

```text
analysis/
  01_stage_clustering/       # Stage-specific QC, clustering and annotation
  02_scanvi_integration/     # Embryonic, postnatal and all-stage scVI/scANVI
  03_embryonic_trajectory/   # Medial/lateral Monocle2 trajectories
  04_hair_cell_trajectory/   # IHC/OHC Monocle2 trajectories
  05_mouse_ush2a/            # Mouse Ush2a analysis
  06_macaque_ush2a/          # Macaque USH2A reanalysis
figures/
  fig1/                      # Figure 1 plotting code
  fig2/                      # Figure 2 plotting code
  fig4/                      # Figure 4 plotting code after removal of RNAscope panel
  common/                    # Shared plotting helpers
tools/validate_repository.py # Fast syntax and portability checks
config/cell_type_markers.xlsx
README.md
.gitignore
```

`config/cell_type_markers.xlsx` is the only analysis configuration file retained: several stage-annotation scripts read it directly. `.gitignore` prevents accidental upload of data, models, figures and temporary files.

## Public data

- Mouse single-cell RNA-seq: [GSE178931](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE178931), [GSE137299](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE137299) and [GSE202920](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE202920).
- Macaque single-nucleus RNA-seq: Chen et al., *Nature Communications* (2026), [DOI 10.1038/s41467-026-68350-2](https://doi.org/10.1038/s41467-026-68350-2); raw reads are under GSA [CRA032615](https://ngdc.cncb.ac.cn/gsa/browse/CRA032615), and the source analysis notebooks are on [GitHub](https://github.com/Shinnyee/Cell-atlas-of-non-human-primate-cochlea).

Place external input files under `Data/`, or keep them elsewhere and set:

```bash
export COCHLEA_DATA_DIR=/path/to/cochlear-data
export COCHLEA_RESULTS_DIR=/path/to/cochlear-results
```

In PowerShell, use `$env:COCHLEA_DATA_DIR` and `$env:COCHLEA_RESULTS_DIR`. Scripts prefer outputs generated by the preceding analysis step and fall back to compatible precomputed objects under `COCHLEA_DATA_DIR`.

The hair-cell and mouse *Ush2a* workflows use the all-stage integrated object plus full-gene E14.5, E16.5, P1, P7, P14 and P28 h5AD files. Exact fallback filenames are defined near the top of the corresponding scripts.

The macaque script expects `Data/macaque/scvi_macaque_cell-type_final.h5ad`, or another file passed with `--input-h5ad`. The published article exposes raw reads and notebooks but no permanent direct download for this processed object, so Fig. 4A–C cannot currently be reproduced from this repository alone.

## Run order

1. Run the nine scripts in `analysis/01_stage_clustering/` in stage order.
2. Run `embryonic_scanvi.py`, `postnatal_scanvi.py` and `all_stages_scanvi.py` in `analysis/02_scanvi_integration/`.
3. Run `analysis/03_embryonic_trajectory/prepare_branch_inputs.py`, followed by the R trajectory scripts in that folder.
4. Run `Rscript analysis/04_hair_cell_trajectory/run_all.R`.
5. Run `Rscript analysis/05_mouse_ush2a/run_all.R`.
6. Supply the processed macaque h5AD and run `analysis/06_macaque_ush2a/macaque_ush2a_reanalysis.py`.
7. Run the panel scripts under `figures/`.

Generated files are written below `COCHLEA_RESULTS_DIR` and are excluded from Git.

## Lightweight validation

This command parses every Python and R source file, checks the repository layout and scans code for local absolute paths or likely credentials. It deliberately does not execute scVI/scANVI or Monocle training.

```bash
python tools/validate_repository.py
```

If `Rscript` is not on `PATH`, set `COCHLEA_RSCRIPT` to the executable first. Several figure scripts also support `--check-inputs`.

## Reproducibility notes requiring manuscript decisions

- The archived integration inputs contain normalized, non-integer values in `.X` and no usable raw-count layer, while the current scVI/scANVI code applies a negative-binomial model to `.X`. Reproducing the existing figures and performing a methodologically standard raw-count scVI analysis are therefore not the same task; the latter requires rebuilding count layers and rerunning integration.
- E9.5, E16.5 and P14 use the shared `single_sample` batch label in the all-stage integration instead of a stage-qualified source-sample label.
- Embryonic Kruskal–Wallis and branch-dependent tests are cell-level analyses without a sample/animal covariate.
- Hair-cell GO/KEGG enrichment currently uses the package-default background rather than an explicitly supplied DGT-derived universe.
- The manuscript reports Python 3.13, whereas the checked analysis environment is Python 3.11.15.

These points should be resolved in the Methods or by reanalysis before the repository is described as a complete end-to-end reproduction package.
